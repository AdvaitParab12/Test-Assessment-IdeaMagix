## Features

- Responsive design for desktop, tablet, and mobile devices
- Mobile navigation menu built using pure JavaScript
- Hero section with treatment information and enquiry CTA
- Treatment navigation section
- Treatment overview with supporting imagery
- Treatment eligibility and preparation information
- About treatment and post-treatment care sections
- Recovery tips section
- Frequently Asked Questions (FAQ)
- Sticky "Need Help?" enquiry form
- Patient stories slider
- Doctors slider
- Hospitals slider
- Responsive footer with contact and social media information
- Lazy loading for images
- Responsive layouts using CSS media queries
- Smooth slider interactions using JavaScript

## Technologies Used

- **HTML5** — Website structure and semantic markup
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Mobile menu, sliders, navigation interactions, and page functionality
